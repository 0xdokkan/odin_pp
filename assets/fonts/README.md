# Font dell'interfaccia M7

**Jersey 10 Regular**, di Sarah Cadigan-Fried, viene incorporato nel renderer
con `#load` e rasterizzato a dimensioni discrete. Il filtro nearest e la
copertura binaria dei glifi mantengono i bordi netti sul canvas 960×540.

- File: [Jersey10-Regular.ttf](Jersey10-Regular.ttf)
- Licenza inclusa: [SIL Open Font License 1.1](Jersey10-OFL.txt)
- Fonte: [Google Fonts — Jersey 10](https://github.com/google/fonts/tree/main/ofl/jersey10)

Il file TTF originale non è modificato. La quantizzazione dei glifi avviene
soltanto sulla texture generata in memoria durante l'avvio del gioco.
